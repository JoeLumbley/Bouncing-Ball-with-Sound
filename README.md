# Bouncing Ball with Sound
This app renders a bouncing ball with a smooth motion trail, plays looping background audio, and triggers bounce sound effects with cooldown logic to prevent audio spam. It uses GDI+, timers, fixed timestep physics, and resource‑extracted MP3 files.
